Create a website using streamlit that allows users to log in and log the fish that they catch. To keep track of the data edit 
the API created with flask in the file api_setup.py. The website will have 4 pages: catches, locations, monsters and species; along with a page for users to log in.
The catch page will allow users to log their catches, they can input the species (for species use only North American freshwater fish), time, date, location, gear they used, 
the length and weight of the fish, along with a picture of the fish. On this page they can also see an overview of all their logged catches.
For the location page, users can add new locations or when they log a catch in a new location, it is automatically added to their locations,
Locations have coordinates, species caught and number of fish caught. On this page add a map using folium that shows all the locations.

If a catch is over a certain threshold length for each species, make that catch be considered a "river monster", create a tab that shows
all of the catches the user has that are "monsters". 
Additionally have a page that shows how many species the user has caught and what number for each species.
